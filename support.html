Common issues

Code does not run: restart NovaCode, confirm you use the latest version and send the console output.

Projects disappeared: do not uninstall or clear app storage before contacting support.

Translation problem: send a screenshot and specify the selected language.

Subscription issue: confirm that you are signed in to the correct App Store account and try Restore Purchases before contacting support.
